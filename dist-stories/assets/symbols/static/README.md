# Статичные символы Asgard Riches

Наборы скопированы 2026-11-03 из экспортов художников без изменения PNG:

- `mobile/` — `/Users/rinat.miazitov/Downloads/1280х720`, обычные символы 112×87, множители 112×112.
- `desktop/` — `/Users/rinat.miazitov/Downloads/1920х1080`, обычные символы 160×124, множители 160×160.

`manifest.json` хранит исходные имена, размеры и SHA-256 каждого файла. Базовые low-символы взяты из `1..5`, не из вариантов `1l..5l` со свечением. Выигрышные PNG-сиквенции по-прежнему находятся в папках `symbols/mobile` и `symbols/desktop`; их позиция и размер подгоняются к выбранному статичному спрайту существующим кодом.

Имена pic-B / pic-D в этих экспортах отличаются от имён папок анимации: сопоставление выполнено по изображению. API ID, таблица выплат, сетка и каменная рамка не изменены.

`src/layout.ts` задаёт прежние media queries интерфейса. Мобильные раскладки получают `mobile`, десктопная — `desktop`; те же пути используются на рилах, в таблице выплат и списке выигрышей. При переходе между раскладками текстуры меняются в покое, а во время спина — после завершения раунда. Координаты ячеек не меняются, сохранена компенсация `aspectFix`.

Высота обычного символа, включая шлем, — 110 единиц ячейки. Множители используют коэффициент 1,25 (137,5 единиц). Видимый масштаб пропорционален по обеим осям, с компенсацией растяжения родительской сетки.
